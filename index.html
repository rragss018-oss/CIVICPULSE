How priority is calculated

Demo score = severity (1–3) × 20 + recency (0–20) + repeated reports at the same named location (0–20). This is a transparent prototype heuristic, not an official risk assessment.

About CivicPulse

CivicPulse is a student concept for community-based reporting of waterlogging, blocked drains and unsafe roads. It organises reports and uses a simple, explainable score to surface possible hotspots.

What works: report submission, local browser storage, filters, report metrics, approximate demo map pins and priority sorting.

Limitations: no backend, no official integration, no incident verification, no secure multi-user database. Map tiles require an internet connection.
